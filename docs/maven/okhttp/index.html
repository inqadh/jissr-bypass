Jissr Bypass OkHttp API

JissrBypassInterceptor

An OkHttp application interceptor that routes exact configured HTTPS hosts through the Jissr Bypass native client.

patch

JissrBypassInterceptor.patch(base, protectedHosts, client, maxRequestBytes)

Clones the base OkHttp client, appends the routing interceptor, and returns the new client. The base client is not mutated.

Compatibility

Bounded request and response bodies are supported. WebSockets, duplex bodies, one-shot bodies, and streaming responses are not supported.
